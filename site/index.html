Controle financeiro doméstico

Uma aplicação em Flask com SQLite para organizar contas, receitas, investimentos, categorias e dashboard mensal.

Visão rápida

  • Dashboard com visão do mês atual e próximos meses.
  • Cadastro de receitas, contas e locais.
  • Gestão de categorias, contas, receitas e investimentos.

Funcionalidades

Dashboard

Resumo financeiro do mês atual, próximos dois meses e acompanhamento de gastos por categoria.

Contas

Cadastro de contas, vencimentos, status e provisionamento automático de contas variáveis.

Receitas

Organização das entradas mensais, receitas previstas e receitas já realizadas.

Investimentos

Registro e acompanhamento de investimentos pessoais e reservas financeiras.

Locais e Categorias

Classificação de despesas, fornecedores e compreensão de movimentos por origem.

Como usar

1. Escolha a versão

Baixe o executável correspondente ao seu sistema operacional na página de Releases do projeto.

Windows

Use o arquivo GestaoFinanceira-Windows.zip ou o executável gerado para Windows, extraia se necessário e execute o programa.

macOS

Use o pacote GestaoFinanceira-macOS.zip e extraia o app antes de abrir a aplicação.

Linux

Use o binário GestaoFinanceira-Linux e conceda permissão de execução, se necessário.

  1. Abra a página de Download da versão mais recente.
  2. Escolha o arquivo para o seu sistema operacional: Windows, macOS ou Linux.
  3. Baixe e execute o pacote ou binário correspondente.
  4. Se o sistema pedir confirmação de segurança, aprove a execução local do aplicativo.

Fluxo de uso recomendado

1. Preparar ambiente

Crie o ambiente virtual e instale as dependências do projeto.

2. Carregar dados

Se tiver histórico em Excel, execute o importador para criar o banco.

3. Navegar pelo dashboard

Use o painel para revisar vencimentos, receitas, investimento e fluxo mensal.

4. Continuar manutenção

Atualize receitas, contas e categorias conforme as necessidades da família.
